突然ですが、僕は、すべての人が自分らしく生き生きと生きている世界をみたいです。

- この世界はもっと自由でもっと広い
- 人にできて、自分にできないことはない
  
この2つは、生まれた頃から培ってきた 変わることのない僕の信念です。

ぼくは幼少期を自然の中で過ごしました。そしてなぜか負けず嫌いで自信家でした。
この２つの特徴のおかげで少し苦労をしました。

小学4年生の体育の授業、ぼくは50mを本気で走っていました。
そのとき、同級生の女の子に笑われました（笑） 
理由を聞きました。ぼくの胸が揺れていて面白かったようです。（少年期のぼくはぽっちゃりでした。）衝撃的でした。ぼくの認知が変わった瞬間その①です。
目の前のことに全力で取り組み、競争に勝つ。負けず嫌いで自信家のぼくは小学4年生のその頃までその認知で生きていました。
だけど、この出来事以降、客観的になり、物事を達観するようになりました。
「競争は無駄だ。勝つものがいるということは、負けるものがいるということだ。別に勝たなくてもいい。」そう考えるようになりました。

「いい高校に入って、いい大学に入る。」これが いい人生ということがなんとなくだけど「当たり前」（そんなことはないと今では分かる）
なんとなくだけど、そんな道がぼくの頭の中にはありました。勉強することの意義はなんとなくのそれでした。 
「競争は無駄だ。」と思っているぼくは、あいつよりいい大学にいってやるといったようなモチベはありませんでした。
それなりに受験勉強をして、第二希望の大学に入りました。

ぼくが入った大学は、大学2年生に進級する際に、1年生の成績で希望の専攻を選べる制度でした。
怠惰だったぼくは、成績が悪く第5希望の専攻になりました。ちょうどこの時期にコロナ禍となり、興味のない難解な数式(ぼくにとっては)を家で1人解かされていました。
怠惰な僕は締め切りの1時間前に宿題に取り掛かり、締め切り時間に間に合わず提出できないことが多々ありました。大学2年の前期は0単位でした。
卒業までの残り3年間で、第１希望のIT専攻で勉強をする同級生たちと、第５希望の別の分野で勉強させられる僕とで差がつくこと想像したときに僕はその未来に堪えられませんでした。
このときのぼくは、自業自得であること・大学に通わせてもらっている身であること・これまで親が生活費や教育費をぼくにかけてくれてきたこと。それを理解できませんでした。

大学2年の後期を休学して、プログラミング

人間が作り上げてきた、国・法律・制度・会社・規範は確かに素晴らしい。
だけど、それによっていつの間にか縛られてはいないだろうか。
カゴの中の鳥になってはいないだろうか。塔の上のラプンツェルになってはいないだろうか。頭の上からニンジンをぶら下げられて、それをくる日もくる日も追いかけ続ける馬のようになってはいないだろうか。
この世界はそんなに狭くない、もっと自由になっていい。誰でもいつからでもやればできる。

自由を求め続けることや希望を持ち続けることは簡単じゃない。
心も身体も知性も鍛える必要がある。

小さなことを積み重ねていく時間が必要だ。

仕事で疲れて、なんとなくSNSを開く。そんな日々を繰り返した自分は、7年後どうなっているだろうか。

他人に奪われまくっている可処分時間を自分に取り戻しませんか。

自分が本当は何をしたいのか。どんな人生を歩みたいのか。どんな夢をもっているのか。そのために今日、1歩先に足を進めることはできたか？
今日という1日は目標に対して何点の1日だったか？
それを踏まえて、明日はどんな1日にしたいか？

自分のために時間を使いませんか。そのあとに、他の誰かのために 行動することができたら嬉しくないですか？

ジャーナルで自分のために時間を使う日々を始めましょう。 65人が自分の人生を取り戻しています(2026/7/3)
